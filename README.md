# rust-html-viewer

2つの HTML の違いを、**見た目（レンダリング結果）とソースの両方で、1画面のまま**確認するためのツールです。
画面やツールを行き来せずに、「どこが・どう変わったか」を追えることを目指しています。

```
cargo run --release -- examples/old.html examples/new.html
```

起動するとブラウザが開きます（`--no-open` で開かない、`--port N` でポート指定）。

ファイルを省略して `cargo run --release` だけで起動すると、ブラウザの画面で比較するファイルを選べます
（パスの貼り付け、またはフォルダを辿って選択）。起動後も `o` キー / 📂 で切り替えできます。

## 画面

- **上：描画結果**（左が旧、右が新）。変更された要素を枠で表示します（ページの CSS には手を加えません）
  - 緑 `+` 追加 / 赤 `−` 削除 / 黄 `~` 変更
- **下：ソースの差分**。行内で変わった部分も強調します。変更のない部分は折りたたみます
- 右端のバーで、ファイル全体のどこに変更があるかが分かります
- **左：変更一覧**。変更ごとの内容を一覧し、クリックでその箇所へ移動します（`l` で表示/非表示）

## 視点を切り替えずに済むための工夫

| 機能 | 内容 |
| --- | --- |
| 変更単位で一斉に移動 | `j` / `k` で次・前の変更へ。旧・新の描画とソースが**同時に**その箇所へスクロール |
| 要素の対応で同期スクロール | 片方をスクロールすると、もう片方の**対応する要素**の位置に合わせる（追加・削除で高さがずれても揃う） |
| 描画 ⇄ ソースの行き来 | 描画の要素をクリック → 該当ソース行へ。ソース行をクリック → 描画のその要素へ。ホバーで行番号とタグを表示 |
| 重ね表示 | `v` で新だけの全幅表示に切替。`Space` を押している間だけ旧を表示（同じ位置で見比べ） |
| ライブ更新 | ファイルを保存すると自動で再読み込み。スクロール位置はそのまま、**編集した箇所へ自動で移動** |
| 描画に影響しない変更 | head や script だけの変更は「描画上の変化なし」と表示 |

## キー操作

| キー | 動作 |
| --- | --- |
| `j` / `n` / `F7` | 次の変更 |
| `k` / `p` / `Shift+F7` | 前の変更 |
| `v` | 並列 ⇄ 重ね |
| `Space`（長押し） | 重ね表示で旧を表示 |
| `w` | 空白の違いを無視 |
| `s` | 同期スクロールの ON/OFF |
| `f` | 編集への追従の ON/OFF |
| `l` | 変更一覧の表示/非表示 |
| `o` | 比較するファイルを選ぶ |
| `?` | キー操作の一覧 |
| `Esc` | ダイアログを閉じる |

## 補足

- ページ内の JavaScript は既定で実行しません（差分を安定させるため）。ヘッダーの「JS」で有効にできます
- CSS や画像は、それぞれの HTML と同じフォルダから相対パスで読み込みます
- ファイル選択のダイアログは、ブラウザの制約でドラッグ&ドロップではパスを取得できないため、パス入力（エクスプローラの「パスのコピー」を貼り付け可）とフォルダ一覧で選びます。API は `localhost` / `127.0.0.1` の Host のみ受け付けます
- 文字コードは UTF-8 / BOM / `<meta charset>` / Shift_JIS を自動判定します

## 仕組み

- Rust（`src/`）: ローカル HTTP サーバー、ファイル監視、ソースの行差分（`similar`）、各タグへのソース行番号の埋め込み（`data-hv-line`）
- ブラウザ（`assets/`）: 2つの iframe で描画し、DOM 同士を比較（LCS）して変更要素を判定。行番号の埋め込みを使って描画とソースを対応付けます
